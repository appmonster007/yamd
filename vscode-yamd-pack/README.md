# YAMD Studio Pack

One install for [YAMD Studio](https://github.com/appmonster007/yamd) and the extensions it works with.

| Extension | What it adds |
|---|---|
| [YAMD Studio](https://marketplace.visualstudio.com/items?itemName=appmonster007.vscode-yamd-ext) | Kanban, calendar, timeline, gallery and SQL query blocks in plain Markdown; callouts, references, citations, diagrams; Build, exports, voice notes and study tools |
| [Foam](https://marketplace.visualstudio.com/items?itemName=foam.foam-vscode) | Wikilinks, backlinks, the note graph, tags and daily notes (YAMD requires it) |
| [SQLite3 Editor](https://marketplace.visualstudio.com/items?itemName=yy0931.vscode-sqlite3-editor) | Edit the SQLite files that queries read |
| [Edit CSV](https://marketplace.visualstudio.com/items?itemName=janisdd.vscode-edit-csv) | Edit the CSV files that queries read |
| [Rainbow CSV](https://marketplace.visualstudio.com/items?itemName=mechatroner.rainbow-csv) | Colour CSV columns and query them with RBQL |
| [Markdown All in One](https://marketplace.visualstudio.com/items?itemName=yzhang.markdown-all-in-one) | List continuation and Markdown shortcuts |

The pack contains no code of its own. Installing YAMD Studio alone brings in the same companions; this pack is for people who prefer to install, update or uninstall them as a group.

See the [YAMD repository](https://github.com/appmonster007/yamd) for documentation, examples and the changelog.
