# Create a note to try things on

**Create Sample Note** writes `welcome-to-yamd.md` and a small CSV next to it, then opens it. It holds a board, a query, a callout and a cross-reference in a few lines each.

**New Note from a Template** starts a real note instead: empty (with contents and bibliography), article, project board, meeting notes, reading list, weekly plan or data note. It asks for a title and a folder.

A YAMD note is **plain Markdown**. Without the extension the widgets are just code blocks, and everything still reads on GitHub.
