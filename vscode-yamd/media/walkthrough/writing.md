# Less typing

**Snippets:** type `kanban`, `calendar`, `timeline`, `gallery`, `query`, `callout`, `theorem`, `card`, `toc` or `figure` and press Tab.

**Completion** suggests widget types after a fence, `source=` files and column names in a query, callout types after `> [!`, citation keys after `[@`, and reference ids after `[@fig-`. Hover a `source=` file to see its columns.

**Insert commands** add the block and its `^id` for you: callouts, figures, tables, equations and citations (they offer to attach a `.bib` file if the note has none).

**Diagrams:** a `mermaid` code block is drawn in the Markdown preview and in exports; type `mermaid` and press Tab.

**Outline and mentions:** the YAMD sidebar's Outline lists headings and callouts, and Unlinked Mentions finds notes that name this one without linking to it.

Pasting an image uses VS Code's own Markdown paste.
