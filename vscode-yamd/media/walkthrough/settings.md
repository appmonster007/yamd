# Settings worth knowing

| Setting | What it does |
|---|---|
| `yamd.build.onSave` | Build whenever you save |
| `yamd.queries.refreshOnSave` | Refresh existing query snapshots on save |
| `yamd.audio.folder` | Where recordings go |
| `yamd.audio.transcribeCommand` | Your speech-to-text tool |
| `yamd.study.reminders` | The daily reminder |
| `yamd.statusBar.enabled` | The status-bar menu item |

Run **YAMD: Open Walkthrough** any time to come back here. Examples to open are in the repository's `examples/` folder.
