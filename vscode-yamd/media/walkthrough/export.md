# Export

- **Export HTML** writes a page with numbered callouts, anchors, static widgets and query tables. Use your browser's Print for PDF; `<!-- yamd:pagebreak -->` starts a new page.
- **Export Slides** makes a deck that steps with the arrow keys.
- **Export as Single Markdown File** writes `name.export.md` with images inlined and query results as tables.
- **Export Widget as HTML** shares one board or query as a read-only page.
