# Deadlines

Tasks with a `{due=YYYY-MM-DD}` date appear in the **Deadlines** list in the YAMD sidebar (grouped as overdue, today, this week and later) and in the study dashboard. A `due` date in a note's front matter counts for the whole note.

## Assignments

- [ ] Problem set 1 {due=2026-11-10}
- [ ] Problem set 2 {due=2026-11-24}
- [ ] Lab report {due=2026-12-01}
- [x] Reading quiz {due=2026-11-03}

## Exams

- [ ] Midterm {due=2026-11-17}
- [ ] Final exam {due=2026-12-18}

Tasks inside a `kanban`, `calendar` or `timeline` block count too:

```kanban revision
## To revise
- [ ] Sorting algorithms {due=2026-11-15}
- [ ] Graph traversal {due=2026-11-28}

## Done
- [x] Big-O notation
```

The study timer (**YAMD: Start Study Timer**) logs focused time per course to `.yamd/study-log.json`, and the dashboard (**YAMD: Open Study Dashboard**) shows progress, streaks and stale topics.
