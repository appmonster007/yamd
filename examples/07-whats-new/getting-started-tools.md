# Menu, templates and the walkthrough

Three ways to find your way around without remembering command names.

- **YAMD: Menu** (or the YAMD item in the status bar) lists every action by task: write, widgets, data, study, share. Pick one to run it. Turn the status-bar item off with `yamd.statusBar.enabled`.
- **YAMD: New Note** asks for a template, a title and a folder, then creates the note and opens it with the cursor in place. Templates: empty note (contents and bibliography already in place), article, project board, meeting notes, reading list, weekly plan, data note.
- **YAMD: Open Walkthrough** is a 14-step tour. It also opens once after install. **YAMD: Create Sample Note** writes a small note and a data file to try everything on.

Try it: run **YAMD: New Note**, choose *Project board*, and open the board the note contains.
